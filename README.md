# Netflix Playback Engine

An interactive, educational prototype that illustrates a high-level Netflix-style video playback flow.

## Demo

Open `index.html` in a web browser. Select an internet connection, then choose **Start Playback** to see the quality response.

## Architecture flow

1. Netflix app
2. Playback services
3. DRM license verification
4. Open Connect CDN delivery
5. Adaptive video player
6. Playback telemetry

> This is an educational model, not a representation of Netflix's private internal systems.
